# ⏰ Alarm Clock using Python

## 📌 Overview

A simple Alarm Clock application built using Python. Users can set an alarm time in HH:MM format, and the application continuously checks the current time. When the specified time is reached, it notifies the user with an alarm sound.

## ✨ Features

* Set an alarm in HH:MM format
* Displays the current time
* Rings an alarm at the specified time
* Simple command-line interface

## 🛠️ Technologies Used

* Python
* datetime module
* time module

## ▶️ How to Run

```bash
python Alarm Clock.py
```

## 📚 Learning Outcomes

* Working with date and time in Python
* Using loops and conditional statements
* Building a simple utility application
